# Security & Privacy Policy

## Client-Side Design Token Execution

**PixelPalette** runs all colour conversions, WCAG 2.1 luminance audits, and token exports locally in your browser. Saved palettes are stored in `window.localStorage` (`pixelpalette_saved_v1`) and are never transmitted over the network.

## Reporting a Vulnerability

Please report security issues via GitHub Issues on `https://github.com/iamnarace/pixelpalette`.
